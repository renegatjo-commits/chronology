Как работает автоматический сбор: после подключения chronology.js в HTML-низ форума откройте Safe Space и откройте тему №1364. Конструктор появится прямо в сообщении. Здесь, на GitHub Pages, доступны ручной конструктор, импорт сохранённого JSON и экспорт HTML. Браузер не разрешает странице GitHub читать закрытые темы форума.
